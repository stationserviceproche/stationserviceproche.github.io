# Station-Service Proche

French-language static site for drivers in France: find cheap fuel near you and save money at the pump.

## Tools (all in French, vanilla JavaScript)
1. **Fuel cost calculator** — trip cost from distance, consumption (L/100 km) and price (€/L).
2. **Trip planner** — total fuel, total cost and refuelling stops for a long journey.
3. **Consumption calculator** — real consumption in L/100 km from litres used and kilometres driven.
4. **Electric vs petrol** — annual energy cost comparison for your yearly mileage.
5. **SP95 vs SP98** — annual savings calculator comparing both fuels.

## Content
- Reference table of French fuels: SP95, SP98, SP95-E10, Diesel, GPL, E85 (octane/cetane, ethanol content, indicative prices).
- 6 French guide articles (cheapest fuel, station services, saving fuel, diesel vs petrol, EV charging, night safety).
- FAQ section and an About/Disclaimer section.

Pure HTML/CSS/vanilla JS, no external libraries or webfonts. Deploy as a GitHub Pages user site at https://stationserviceproche.github.io/
